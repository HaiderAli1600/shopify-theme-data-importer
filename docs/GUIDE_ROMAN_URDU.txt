1) EXE KAISE BANEGI  (sirf ek dafa, apne PC par)
----------------------------------------------------------------
  a. Is PC par Python 3.10 ya naya install hona chahiye:
     https://www.python.org/downloads/
     (install karte waqt "Add python.exe to PATH" par tick lagao)

  b. "build_exe.bat" par double click karo.
     - Yeh khud alag build environment banata hai, libraries
       install karta hai aur EXE bana deta hai (2-4 minute).

  c. EXE yahan milegi:
        dist\Shopify Theme Data Importer.exe

  d. Yeh EK file kisi ko bhi de do. Us PC par kuch install nahi
     karna -- Python aur saari libraries EXE ke andar hain.
     Icon tool ka logo hai.

  Windows "Windows protected your PC" dikhaye to:
     More info  ->  Run anyway   (EXE signed nahi, is liye)


2) TOOL KAISE CHALTA HAI
----------------------------------------------------------------
  - EXE double click -> animated loader -> tool ki window khulti
    hai (Microsoft Edge ka app-window, jo Windows me pehle se
    hota hai). Edge na mile to default browser me khulta hai.
  - Sab kuch aap ke PC par chalta hai (127.0.0.1). Data kisi aur
    server par nahi jata. Tokens kahin save nahi hote.
  - Window band karo = tool band.
  - Theme ZIP backups aur logs yahan save hote hain:
        Documents\Shopify Theme Data Importer\


3) CHAAR MODES
----------------------------------------------------------------
  Store -> Store       Apne store se client ke store par EXACT
                       migration: files, products, collections
                       (smart rules ke saath), blogs, pages, menus,
                       metafields, theme copy + verify.
  Theme Demo -> Store  Envato/ThemeForest password demo se section
                       images, products, collections, blogs, pages.
  WooCommerce -> Shopify  Products, variants, sale price, stock,
                       images, categories, SEO redirects.
  Blog Import          Kisi bhi website ke blogs (WordPress API
                       auto-detect, baaqi sites smart scraping).

  Har field ke saath "?" dabao -> right side par Roman Urdu guide.
  Left menu -> "Guide" me Dev Dashboard app banane ka har step.

  Dobara chalao to jo pehle aa chuka hai woh SKIP hota hai --
  duplicate nahi banta.


4) ADMIN API ACCESS -- DEV DASHBOARD APP KAISE BANAYEIN
----------------------------------------------------------------
  (Tool ke andar: API Access / Token Lab -> "Setup Guide", har
   value ke saath Copy button. Connector par "Setup guide" button.)

  A) CLIENT KA STORE  (Destination -- aap ki organization me nahi)
     Tool me tareeqa: "Client store (OAuth)"
     1. dev.shopify.com -> Apps -> Create app (har client ki alag app)
     2. URLs:
          App URL ........................ https://example.com
          Embed app in Shopify admin ..... UNTICK
          Allowed redirection URL(s) ..... http://localhost:8765/oauth/callback
          Use legacy install flow ........ UNTICK
     3. API access -> Scopes:
          write_products,write_inventory,read_locations,write_files,write_content,write_online_store_navigation,write_themes
     4. Baaqi fields (Webhooks API version waghera) jaise hain waise
        chhor do -> upar "Create app".
     5. Distribution -> Custom distribution:
          Store domain ... client-store.myshopify.com
                           (https:// ke baghair, aakhir me / NAHI)
          Allow multi-store install for one Plus organization: UNTICK
          -> Generate link
     6. Link client ko bhejo, woh Install kare (ya aap, agar client
        store par apps install karne ki permission hai).
     7. App -> Settings -> Client ID + Client secret copy.
     8. Tool -> Destination -> "Client store (OAuth)" -> dono paste
        -> "Authorize (browser me)" -> Shopify par Approve.
        Browser me "Token tayar hai" -> tool me green tick.
     9. Saare scopes green = destination tayar. Phir Source connect
        karo aur "Migration shuru karo".
     Localhost redirect save na ho: https://example.com/callback daalo,
     approve ke baad ka poora URL (?code= wala) tool me "Paste URL".

  B) APNA STORE  (Source -- aap ki organization ka store)
     Tool me tareeqa: "Client ID + Secret"
     1. dev.shopify.com -> Apps -> Create app
     2. App URL https://example.com | Embed UNTICK |
        Redirect khali | Legacy install flow UNTICK
     3. Scopes (source, sirf read):
          read_products,read_inventory,read_files,read_content,read_online_store_navigation,read_themes
        (Agar yahi store destination hai to upar wali write list.)
     4. Baaqi fields default -> Create app
     5. App Home -> Install app -> apna store -> Install
     6. Settings -> Client ID + Secret -> tool -> Source ->
        "Client ID + Secret" -> "Token banao & Test"
        (token 24 ghante ka, tool khud renew karta hai)
     Doosra tareeqa: store me Settings -> Apps -> Develop apps se
     legacy custom app ban sakti ho to shpat_ token -> "Access Token".

  C) KIS MODE ME KYA
     Store -> Store ......... Source (read list) + Destination (write list)
     Theme Demo -> Store .... Destination: write_products, write_files,
                              write_content, read_themes
     WooCommerce -> Shopify . Destination: write_products, write_inventory,
                              read_locations, write_online_store_navigation
                              + WooCommerce -> Settings -> Advanced ->
                              REST API -> Add key (Read) -> ck_ / cs_
     Blog Import ............ Destination: write_content, write_files
     Asaan: har destination app me poori write list daal do.


5) FOLDER ME KYA HAI

6) MIGRATION KE BAAD
----------------------------------------------------------------
  * Finish report me "Theme '...' (config/settings_data.json):
    shop_images/x.jpg store me NAHI hai" aaye to:
    theme settings kisi image ka naam yaad rakhti hai. Tool source
    store me check karta hai -- wahan mil jaye to khud copy kar
    deta hai, wahan bhi na ho to woh purana demo reference hai
    (store par koi asar nahi). Jo note phir bhi rahe, Theme
    customizer me us section ki image dobara select kar do.
  * Sirf yeh check dobara chalana ho: Store -> Store me sirf
    "Files" aur "Verify" tick karo -> Migration shuru karo.
  * Naya theme "(migrated)" naam se UNPUBLISHED banta hai:
    Online Store -> Themes -> Preview -> theek ho to Publish.
  * Theme ZIP aur logs:  Documents\Shopify Theme Data Importer\
    (tool me upar "Output folder" button).
